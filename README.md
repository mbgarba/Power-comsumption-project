# ⚡ Power Consumption Analysis Project

This project was created to analyze energy usage data from multiple meters over time, with the aim of understanding consumption patterns, detecting anomalies, and identifying data quality issues that could inform smarter energy management.

🎯 What this project was done to do:

*Explore large‑scale time‑series energy data recorded every 15 minutes across 172 meters.

*Detect and visualize missing data to assess device reliability and data health.

*Uncover seasonal, monthly, and daily consumption trends to support operational insights.

*Build a foundation for further analytics like anomaly detection, forecasting, and optimization.
